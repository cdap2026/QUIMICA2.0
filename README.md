# Taller Web Interactivo: Unidades Químicas de Concentración

Esta es una aplicación web educativa de un solo archivo (Single-File HTML) diseñada para estudiantes de química de grado 10°.

## Novedades de esta versión
- Se agregó el desglose teórico completo de **todas las unidades físicas y químicas de concentración**.
- Cada unidad cuenta ahora con su **definición formal**, la **fórmula matemática**, un **ejercicio completamente resuelto paso a paso**, y **aplicaciones en la vida diaria**.
- Se optimizó el marcado en **HTML5 semántico** (`<article>`, `<section>`, `<header>`, `<main>`).

## Características
- **Lectura con Timer:** 15 minutos obligatorios para revisar la teoría antes de habilitar el cuestionario.
- **Cuestionario:** 10 preguntas tipo prueba saber (opción múltiple) y 3 preguntas abiertas de desarrollo.
- **Anti-Copia:**
  - Deshabilitado el menú contextual (copiar, pegar, cortar).
  - Bloqueo de selección de texto.
  - Penalización automática si el estudiante cambia de pestaña (-1.0 la primera vez, y finalización de la prueba a la segunda).
- **Reporte PDF y QR:** Generación de un PDF detallado de las respuestas para entregar al docente, junto con un código QR con el resumen.

## Cómo publicar en GitHub Pages
1. Crea una cuenta en [GitHub](https://github.com/) si no tienes una.
2. Crea un nuevo repositorio y nómbralo (por ejemplo, `taller-quimica`).
3. Sube el archivo `index.html` a tu nuevo repositorio.
4. Ve a la pestaña **Settings** (Configuración) de tu repositorio.
5. En la barra lateral izquierda, haz clic en **Pages**.
6. En *Source* (o *Branch*), selecciona `main` o `master` y guarda.
7. Espera unos minutos y GitHub te dará un enlace público (ej. `https://tu-usuario.github.io/taller-quimica/`) que podrás compartir con tus estudiantes.
